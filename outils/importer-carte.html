Mettre la carte à jour — KING FOOD

Le code QR imprimé ne change jamais : il pointe vers hospiceantonio.github.io/kingfood/. Vous remplacez seulement le fichier menu.json et la nouvelle carte apparaît sur les téléphones.

1 · Charger Récupérez la carte actuellement en ligne, puis modifiez le texte : prix, plats, catégories.
2 · Télécharger Quand tout est vert, téléchargez le nouveau menu.json.
3 · Déposer Glissez ce fichier sur GitHub dans le dossier king-food/ et validez. En 1 à 2 minutes la carte est à jour.

La carte, en texte

Coordonnées du restaurant (pied de page et boutons de la carte)
Le format, en trois règles : 
# La carte               ← une ligne « # » ouvre une carte (facultatif s'il n'y en a qu'une)
## Burgers | Prix : sandwich / assiette     ← « ## » ouvre une catégorie ; après « | », une note
44-45 - Chicken Burger | 4000 / 5000        ← Numéro - Nom | Prix (deux prix séparés par « / »)
64-65 - Burger King Food | jambon, viande, fromage | 5000 / 6000   ← Nom | Description | Prix
70 - Club Sandwich | 6000                   ← la description est facultative, le numéro aussi
Les prix s'écrivent 3500 ou 5000 / 6500 (petit / grand, sandwich / assiette…) ; un prix vide est accepté (ex. la liste des accompagnements). Vous pouvez aussi coller des lignes venant d'Excel (colonnes Nom, Description, Prix). Les numéros de plats servent à commander au comptoir : la recherche du menu les retrouve.

Vérification et aperçu

Rien à afficher pour l'instant.
    3 · Déposer sur GitHub

    Sur GitHub : glissez menu.json dans la zone, laissez « Commit directly to the main branch », puis cliquez sur Commit changes. La publication est automatique.
